Note (Jetson / L4T):
- We do NOT install torch / torchvision from PyPI, because the Jetson L4T ML container already provides the correct ARM64 builds.
- TensorRT and pycuda are also provided by the container.
- torch2trt is included in this repository. Install it once inside the container:
    cd /workspace/torch2trt && python3 setup.py install
- If any of the versions above do not match (e.g. numpy, matplotlib), you can run:
    pip3 install -r requirements.txt --force-reinstall
